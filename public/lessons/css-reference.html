What is CSS?

CSS (Cascading Style Sheets) controls the visual presentation of HTML. While HTML defines structure, CSS defines colour, layout, spacing, fonts, animations, and more. Together they are the backbone of every webpage.

🎨

Style

Control colours, fonts, sizes, and visual effects on any HTML element.

📐

Layout

Flexbox and Grid give you powerful, two-dimensional control over page layouts.

📱

Responsive

Media queries adapt designs to any screen size from phone to ultrawide monitor.

✨

Animation

Transitions and animations bring interfaces to life without JavaScript.

🔧

Variables

Custom properties let you store and reuse values across your entire stylesheet.

♿

Accessible

Good CSS ensures content is readable and navigable for everyone, including screen reader users.

💡 The Cascade

CSS is cascading — when multiple rules target the same element, the browser decides which wins using specificity, source order, and inheritance.

Syntax & Selectors

CSS rules target HTML elements using selectors. Understanding how to write selectors — and how specificity resolves conflicts — is fundamental to mastering CSS.

Anatomy of a CSS Ruleset
CSS
p {                     /* selector */
  color: blue;           /* declaration */
  font-size: 18px;       /* property: value */
}

Selector

Targets the HTML element(s) to style — e.g. p, .class, #id

Declaration Block

Everything inside { } — one or more declarations

Declaration

A single property: value pair ending with ;

Three Ways to Include CSS
MethodWhereBest For
External.css file via <link>Production (preferred)
Internal<style> in <head>Single-page overrides
Inlinestyle="" attributeQuick tests, emails
HTML
<!-- External -->
<link rel="stylesheet" href="style.css">

<!-- Internal -->
<style>
  p { color: red; }
</style>

<!-- Inline -->
<p style="color:blue">Hello</p>
Selector Types
CSS — ALL SELECTOR TYPES
/* Type — targets all elements of that tag */
p { color: green; }

/* Universal — targets everything */
* { font-family: Verdana; }

/* Class — targets elements with that class */
.brand { color: purple; }

/* ID — targets one unique element */
#main-title { font-size: 2rem; }

/* Attribute selectors */
[href] { color: magenta; }
img[src*="photo"] { height: 100px; }

/* Chaining — element must match both */
h1.special { color: teal; }

/* Descendant — li inside .menu */
.menu li { color: blue; }

/* Grouping — same style for multiple selectors */
h1, h2, .title { font-family: Georgia; }
Pseudo-Classes
Pseudo-classes target elements in a specific state.
:hover:active:focus:visited :first-child:last-child:nth-child(n) :not():checked:disabled:placeholder
CSS
a:hover { color: purple; }
button:active { transform: scale(0.98); }
input:focus { border-color: blue; outline: none; }
li:first-child { font-weight: bold; }
li:nth-child(odd) { background: #f5f5f5; }
Specificity — Who Wins?
When two rules target the same element, the one with higher specificity wins.

⚠️ Avoid !important

Using !important overrides all other specificity rules and makes debugging very difficult. Use it only as a last resort.

Adding !important to a declaration overrides all other rules for that property. Useful as a last resort but makes maintenance difficult.

The Box Model

Every HTML element is a rectangular box. The box model defines how its total space is calculated using content, padding, border, and margin.

Padding & Margin Shorthand
CSS
/* 4: top right bottom left */
padding: 10px 20px 10px 20px;

/* 2: top+bottom | left+right */
padding: 10px 20px;

/* Center element horizontally */
div { width: 400px; margin: 0 auto; }
Border
CSS
p {
  border: 3px solid coral;
  border-radius: 8px;
  border-top: 2px dashed blue;
}
Box-Sizing
By default (content-box), padding and border are added to the declared width. Use border-box to include them inside the width.
CSS
/* Recommended global reset */
* { box-sizing: border-box; }

/* content-box (default):
   200px + 20px padding = 220px total
   border-box:
   always 200px — padding inside */
Overflow & Visibility
CSS
p { overflow: scroll; /* hidden | visible */ }

/* visibility: hidden — space preserved */
.hidden { visibility: hidden; }

/* display: none — removed from flow */
.gone { display: none; }
✅ Universal Reset

Start every stylesheet with * { margin: 0; padding: 0; box-sizing: border-box; } to remove browser default spacing inconsistencies.

CSS Colors

CSS supports named colours, hexadecimal, RGB, and HSL — each with optional alpha transparency. Understanding HSL especially helps when building consistent colour systems.

Color Formats
CSS
color: red;                       /* named */
color: #c084fc;                   /* hex */
color: #c08;                      /* shorthand hex */
color: rgb(192, 132, 252);        /* rgb 0–255 */
color: rgba(192, 132, 252, 0.5);  /* alpha 0–1 */
color: hsl(270, 95%, 75%);        /* hue saturation lightness */
color: hsla(270, 95%, 75%, 0.8);  /* hsl + alpha */
Understanding HSL
🎯

Hue (0–360°)

Angle on the colour wheel. 0°=red, 120°=green, 240°=blue.

💧

Saturation (0–100%)

Intensity of the colour. 0% = grey, 100% = vivid full colour.

☀️

Lightness (0–100%)

Brightness. 0%=black, 50%=normal, 100%=white.

Clickable Swatches

Click a swatch to copy its hex value.

Alpha Transparency
CSS
/* RGBA — 0 transparent, 1 opaque */
background: rgba(0, 0, 0, 0.5);     /* 50% black */

/* Hex with alpha — last 2 digits */
background: #c084fc80;              /* ~50% opacity */
background: #c084fc00;              /* fully transparent */
background: #c084fcFF;              /* fully opaque */

CSS Typography

Typography properties control every aspect of how text looks and reads — from font choice and weight to spacing, alignment, and custom web fonts.

Font Stack & Web-Safe Fonts
List multiple fonts in order of preference. The browser uses the first one it finds installed; the last value should always be a generic family fallback.
CSS
h1 {
  font-family: Caslon, Georgia, 'Times New Roman', serif;
}
p {
  font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif;
}
Custom Fonts
Google Fonts — link in your HTML head, then use in CSS:
HTML + CSS
<!-- HTML head -->
<link href="fonts.googleapis.com/...">

/* CSS */
body { font-family: 'Inter', sans-serif; }
Self-hosted — using @font-face:
CSS
@font-face {
  font-family: 'MyFont';
  src: url('fonts/MyFont.woff2')
       format('woff2');
  font-weight: normal;
}

CSS Transitions

Transitions animate property changes over time — no JavaScript required. They trigger on state changes like :hover, :focus, or class toggling.

Transition Properties
CSS
/* Individual properties */
a {
  transition-property: color;
  transition-duration: 1s;
  transition-timing-function: ease-out;
  transition-delay: 0s;
}

/* Shorthand: property duration timing delay */
a { transition: color 1s ease-out 0s; }

/* Multiple transitions */
.btn {
  transition: color 0.3s ease,
              background-color 0.3s ease,
              transform 0.2s ease-in;
}

Flex Item Properties

      

        
CSS

        
.side   { flex-grow: 1; flex-shrink: 1; flex-basis: 100px; }
.center { flex-grow: 2; flex-shrink: 1; flex-basis: 150px; }

/* Shorthand: grow shrink basis */

Main Axis
Controlled by flex-direction (row or column). Use justify-content to space items along it.

        
Cross Axis
Perpendicular to the main axis. Use align-items (single line) or align-content (multiple lines).

CSS Grid is a two-dimensional layout system giving control over both rows and columns simultaneously. Ideal for page-level layouts and complex UI patterns.

Grid Properties Reference

      

        
CSS

        
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 100px auto;
  gap: 20px 10px;         /* row-gap column-gap */
}

/* Named template areas */
.container {
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
}
header { grid-area: header; }

/* Item spanning */
.item { grid-column: 1 / 3; }   /* cols 1–2 */
.item { grid-row: 1 / span 2; } /* 2 rows */

      

    


    

      
Useful Grid Functions

      

        
CSS

        
/* repeat() */
grid-template-columns: repeat(4, 1fr);

/* minmax() */
grid-template-columns: repeat(3, minmax(100px, 1fr));

/* auto-fill — responsive columns with no media queries! */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* fr — fraction of remaining space */
grid-template-columns: 1fr 2fr 1fr; /* 25% 50% 25% */

Media Queries

      

        
CSS

        
/* Mobile first — enhance as screen grows */
body { font-size: 14px; }

@media only screen and (min-width: 768px) {
  body { font-size: 16px; }
  .container { max-width: 720px; }
}

@media only screen and (min-width: 1024px) {
  .container { max-width: 960px; }
}

/* High-resolution / retina screens */
@media only screen and (min-resolution: 2dppx) {
  .logo { background-image: url(logo@2x.png); }
}

/* Orientation */
@media (orientation: landscape) {
  .hero { height: 60vh; }
}

      

      
✅ Mobile-First Approach
Write your base styles for small screens, then use min-width media queries to add complexity for larger screens. This is more performant and easier to maintain than desktop-first.

    

  







  

    
Variables & Functions

    
CSS custom properties (variables) let you define reusable values. CSS functions perform dynamic calculations directly in your stylesheets.

  

  

    

      
CSS Custom Properties (Variables)

      

        
CSS

        
/* Global scope — declare in :root */
:root {
  --color-primary: #c084fc;
  --font-size-base: 16px;
  --spacing-lg: 32px;
  --border-radius: 8px;
}

/* Usage with var() */
.button {
  background: var(--color-primary);
  border-radius: var(--border-radius);
}

/* Fallback value */
.text { color: var(--text-color, #e2e8f0); }

/* Responsive variables */
@media (max-width: 768px) {
  :root {
    --font-size-base: 14px;
    --spacing-lg: 20px;
  }
}

      

    


    

      
CSS Functions

      

        
calc()
Mathematical calculations
▼

        

          
CSS

            
.item { width: calc(100% - 40px); }
.item { margin: 15px calc(1.5vw + 5px); }
.item { height: calc(100vh - 60px); }

          

        

      

      

        
clamp()
Fluid value within bounds
▼

        

          
CSS

            
/* clamp(min, preferred, max) */
.text { font-size: clamp(14px, 2vw, 24px); }
.hero { padding: clamp(20px, 5vw, 80px); }

          

          
✅ Fluid Typography
clamp() is the best way to create responsive font sizes without any media queries. The preferred value scales with viewport, clamped between min and max.

        

      

      

        
min() / max()
Pick smallest or largest value
▼

        

          
CSS

            
.content { width: min(600px, 90%); } /* never wider than 600px */
.sidebar { width: max(200px, 20%); } /* never narrower than 200px */

CSS Accessibility

    
Good CSS doesn't just look nice — it ensures content is readable, navigable, and usable by everyone, including users of assistive technologies.

  

  

    

      

        

          
Text Readability

          
CSS

            
body {
  font-size: 18px;       /* min 16–18px */
  line-height: 1.6;      /* min 1.5 */
  max-width: 70ch;       /* 45–85 char */
  text-align: left;      /* avoid justify */
}

          

        

        

          
Focus & Interactive States

          
CSS

            
/* Never remove focus outlines! */
input:focus, button:focus {
  outline: 3px solid #c084fc;
  outline-offset: 2px;
}
a { text-decoration: underline; }
.btn { cursor: pointer; }

⚠️ Avoid colour-only cues
Never convey meaning through colour alone. Always pair colour with text labels, icons, or patterns.

        

        

          
Hiding Content

          
CSS

            
/* Hidden from all */
.gone { display: none; }
.inv  { visibility: hidden; }

/* Visually hidden, readable by screen readers */
.sr-only {
  position: absolute;
  width: 1px; height: 1px;
  overflow: hidden;
  clip: rect(0,0,0,0);
}

          

        

      

    

    

      
Print Styles

      
CSS

        
@media print {
  nav, footer, .ads { display: none; }
  body { font-size: 12pt; color: #000; }
  /* Show URLs after links when printed */
  a[href^="http"]:after {
    content: " (" attr(href) ")";
  }
}

      

    

  







  

    
Browser Compatibility

    
Browsers render CSS slightly differently. Modern techniques like @supports, vendor prefixes, and progressive enhancement ensure your styles work reliably everywhere.

  

  

    

      
Vendor Prefixes

      
CSS

        
.box {
  -webkit-transform: rotate(15deg); /* Chrome, Safari */
  -moz-transform:    rotate(15deg); /* Firefox */
  -ms-transform:     rotate(15deg); /* IE/Edge */
  transform:         rotate(15deg); /* standard */
}

      

      
✅ Use Autoprefixer
The Autoprefixer PostCSS plugin automatically adds the right vendor prefixes — no manual work needed.

    


    

      
Feature Queries (@supports)

      
CSS

        
/* Default — all browsers */
.gallery { display: inline-block; margin: 10px; }

/* Enhanced — only if grid is supported */
@supports (display: grid) {
  .gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
  }
}

/* Not supported */
@supports not (display: grid) { ... }

/* Combining conditions */
@supports (display: grid) and (gap: 10px) { ... }

      

    


    

      
Progressive Enhancement vs Graceful Degradation

      

        

          
🌱

          
Progressive Enhancement

          
Start with basics that work everywhere, then layer enhancements for modern browsers. More future-proof and modular.

        

        

          
🪂

          
Graceful Degradation

          
Start with full features for modern browsers, then provide fallbacks for older ones. Easier for existing complex projects.

        

      

      
💡 Check Support
Use caniuse.com to check browser support for any CSS feature before using it.
